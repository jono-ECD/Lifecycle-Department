# Growth & Analysis Work Flow

The automated reporting and diagnosis loop: pull performance, compare against targets, surface the bottleneck, and draft the narrative. Turns `marketing-strategy/account-growth-analysis` from a manual monthly scramble into a standing process.

## Inputs
- Performance data (Klaviyo, Hiro, platform)
- Targets from the retention thesis
- Prior period results and test history

## Outputs
- Recurring performance report
- Flagged anomalies and threshold breaches
- Draft diagnosis and recommended actions

## Depends on
Data access per `clients/registry.yml` — accounts with no connector cannot run this. `onboarding-migration/marketing-analytics-personalization` must be sound first.
