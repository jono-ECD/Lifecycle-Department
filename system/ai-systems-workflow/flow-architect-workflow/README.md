# Flow Architect Work Flow

Translating a purchase journey into a concrete flow build: triggers, filters, timing, branching, and message sequence. The bridge between strategy and implementation, and the workflow with the highest leverage per hour invested.

## Inputs
- Purchase journey map with gaps identified
- Retention thesis and priority cohorts
- Existing flow inventory
- Catalog and replenishment model

## Outputs
- Flow specification (triggers, filters, delays, branches)
- Message-level brief per step
- Build-ready spec handed to implementation

## Depends on
`marketing-strategy/purchase-journey` and `retention-strategy`. Output feeds `onboarding-migration/full-implementation`; gated by `qa-workflow`.
