# Marketing Analytics (Personalization)

The measurement and personalization substrate: event tracking, catalog integration, custom properties, and the data model that makes everything downstream targetable. Underbuilt here means every strategy above it is guessing.

## Inputs
- Platform event schema and catalog feed
- Existing custom properties and metric definitions
- Reporting questions the client actually asks

## Outputs
- Verified event and catalog integration
- Custom metric and property definitions
- Personalization blocks and dynamic content
- Reporting views tied to real decisions

## Depends on
Prerequisite for `marketing-strategy/account-growth-analysis` and `ai-systems-workflow/growth-analysis-workflow` — neither is trustworthy without it.
