# Product / Service Strategy

How the catalog itself drives lifecycle: entry products, margin structure, replenishment cycles, bundling, and cross-sell logic. Determines what the program should push and when, independent of creative.

## Inputs
- Catalog with margin and cost data
- Purchase sequence and repeat-rate analysis
- Replenishment cycle and consumption rate
- Inventory and seasonality constraints

## Outputs
- Entry-product and hero-product definition
- Cross-sell and upsell matrix
- Replenishment timing model
- Bundling and offer architecture

## Depends on
`onboarding-migration/marketing-analytics-personalization` for catalog integration.
